# Release and signing

Releases come from `main`. Packages are published to crates.io, PyPI, npm, Maven, Go and GitHub Packages ([issue #254](https://github.com/ostrium-labs/loams/issues/254)). Desktop, CLI and mobile artifacts are signed with SignPath ([issue #253](https://github.com/ostrium-labs/loams/issues/253)). Each release should ship an SBOM.

Both are in progress; the repo's workflows and CHANGELOG are the source of truth.
