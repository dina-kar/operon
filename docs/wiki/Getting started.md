# Getting started

1. Install the Rust toolchain pinned in `rust-toolchain.toml`.
2. Clone the repo and run a dev server; the steps and the first hybrid search are in the [README quick start](https://github.com/ostrium-labs/loams/blob/main/README.md#quick-start).
3. Try an existing Qdrant client or Flight SQL against it (same README).

Developer setup, tests and the PR flow: [CONTRIBUTING.md](https://github.com/ostrium-labs/loams/blob/main/CONTRIBUTING.md). Keep Rust builds light: use the repo's cargo config and don't run a full-parallel build on a small machine.
