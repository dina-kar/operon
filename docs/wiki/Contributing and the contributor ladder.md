# Contributing and the contributor ladder

1. **Anyone** can open a PR to `dev`.
2. **A first merged PR** adds you to the `committers` team.
3. **Maintainers** merge `dev` into `main`; any maintainer can add trusted people to the teams.

Every commit needs a DCO sign-off (`git commit -s`). Keep PRs small, with tests. Details: [CONTRIBUTING.md](https://github.com/ostrium-labs/loams/blob/main/CONTRIBUTING.md) and [GOVERNANCE.md](https://github.com/ostrium-labs/loams/blob/main/GOVERNANCE.md).
