# Marketplace developer guide

How an OSS project or vendor lists in the Loams Cloud marketplace: the open package, consent scopes, signed releases, SBOMs, the submission flow, listing assets and support duties. Revenue terms are to be announced.

Read [Publish your project to the Loams Cloud Marketplace](https://github.com/ostrium-labs/loams/blob/main/docs/marketplace/publishing.md). The marketplace is not live yet.
