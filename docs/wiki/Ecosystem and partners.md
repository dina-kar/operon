# Ecosystem and partners

**Upstream first.** OSS projects and companies may fork, embed, host and build commercial products on Loams (Apache-2.0). We ask that you upstream the changes Loams needs: Discussion, then an RFC issue, then PRs to `dev`.

- Policy, extension points and worked examples (illustrations only): [ECOSYSTEM.md](https://github.com/ostrium-labs/loams/blob/main/ECOSYSTEM.md)
- Using the name: [TRADEMARKS.md](https://github.com/ostrium-labs/loams/blob/main/TRADEMARKS.md). "Built on Loams" is fine; don't name a product "Loams" without permission.
- See [[Building a product on Loams]], [[Deploy buttons]] and [[Marketplace developer guide]].
