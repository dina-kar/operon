# M1.6 — SDKs and MCP Server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Execute task by task, test first. Each task lists the interfaces it must produce and the tests that must exist and pass before it is done. Where this plan gives exact values (names, paths, formats, constants), use them verbatim. The code is not pre-written in this plan (M0.3 Ruling 1).

> **Status: Planned** (2026-09-24).

**Goal:** Ship:
- `operon-client`, a Python SDK (sync and async) for the native REST API: namespaces, streams (produce/fetch), collections, documents (dense and sparse vectors), the hybrid query IR (sparse retrievers included, overview A29) through a typed builder, SQL, consistency tokens, typed errors and retries, with an optional `flight` extra that returns Arrow tables over Flight SQL and bulk-loads Arrow data into collections and streams through Flight SQL ingest (D49), `to_arrow()` and `to_polars()` on query and SQL results through the Arrow PyCapsule interface (optional extras `arrow` and `polars`, D54), and a thin `scan_plan()` over M1.2's scan-plan route (D53);
- `@operon/client`, a TypeScript SDK with the same REST surface (`scanPlan()` included), `fetch`-based, zero runtime dependencies, ESM with types, for Node ≥ 22 and browsers; it has no Arrow results in M1 (Ruling 17);
- `operon-mcp`, the W0 MCP server (design §15 §10.1, §13 row W0): five tools (`search`, `sql`, `memory_write`, `list_collections`, `get_documents`) on MCP 2026-07-28, stateless, mounted at `/mcp` on the native REST listener, so Claude Code, Codex and opencode can use Operon as a tool server;
- a shared wire-fixture corpus that the server and both SDKs test against, so the three stay in step.

**Architecture:**
- The SDKs speak only the native REST API (overview §6.8). Each SDK has exactly one module that knows the wire JSON (`operon/_wire.py`, `src/wire.ts`); everything else works on the SDK's own types. Task 0 reconciles that module with the as-built M1.2 API; the corpus in `sdks/fixtures/` pins it (Task 1).
- Python: `httpx` for the sync and async transports, frozen `dataclasses` for every value type, one pure encoder/decoder shared by `Client` and `AsyncClient`. Flight SQL queries and ingest (`adbc_ingest`) go through ADBC (`adbc-driver-flightsql`), imported only by `operon.flight`. Arrow and Polars conversions live in `operon.arrow`, imported only when `to_arrow()`, `to_polars()` or `__arrow_c_stream__` is called.
- TypeScript: global `fetch` and `AbortSignal`, lossless u64 ids through `JSON.parse` source-text access and `JSON.rawJSON`, compiled by `tsc` to `dist/` (ESM + `.d.ts`); tests with `node:test` against the built output.
- `operon-mcp`: an `rmcp` 3.4.1 `ServerHandler` over `CollectionService` (gateways never reach storage: overview §8). It is served by `StreamableHttpService` with `NeverSessionManager`, `legacy_session_mode(false)` and `json_response(true)`, and nested into the `operon` binary's axum router with `nest_service("/mcp", …)` behind the `mcp` cargo feature (on by default).
- CI: one job builds the `operon` debug binary once; `sdk-python` and `sdk-typescript` download it and run their suites against a spawned `operon dev`.

## Global Constraints

Same as the M1 overview §8, plus:
- Python SDK: pure Python, no compiled extensions, Python ≥ 3.10; runtime dependencies are exactly `httpx` and `anyio` (plus the optional extras: `flight`'s three, `arrow`'s `pyarrow`, `polars`'s `polars` and `pyarrow`). `import operon` imports none of the extras' packages. `ruff check`, `ruff format --check`, `mypy --strict src tests` and `pytest` pass after every Python task.
- TypeScript SDK: zero runtime dependencies; nothing under `src/` imports a Node built-in or uses `process`, `Buffer` or `require`, so the build runs in browsers. `biome check`, `tsc` (build and test configs) and `node --test` pass after every TypeScript task.
- Both SDKs: every wire-format fact lives in the one wire module; JSON is never produced with a non-finite number (checked before sending); u64 ids never lose precision.
- SDK tests reach no network except the `operon dev` child they spawn on `127.0.0.1:0`.
- `operon-mcp` opens no listener of its own: it is served only through the native listener. It never calls a storage, meta or log API directly: only `CollectionService`.
- Commit areas used by this plan: `sdk`, `mcp`, `operon`, `ci`, `docs`, and `query` only for Task 8's conditional `ensure_namespace` commit.

## Assumed native wire contract

Derived from overview §6.5–§6.8 and the M0 API as built (`crates/operon/src/api.rs`). Rules: JSON bodies are the serde form of the IR types with `snake_case` field names and `snake_case` enum variants, externally tagged (unit variants are strings, struct variants are single-key objects); `Option::None` is `null`. **Every row is an assumption for Task 0 to diff** except those marked "M0".

**Ids (`PrimaryKey`)**: a JSON integer in `0..=18446744073709551615` is `U64`; a JSON string is `Str`; `{"uuid": "<8-4-4-4-12 lowercase hex>"}` is `Uuid`. **Consistency token**: the §6.5 text form, e.g. `"v1:s7/p3@918274,s7/p4@12"`; grammar `v1:` then zero or more items `s<dec>/p<dec>@<dec>` joined by `,`, `<dec>` = `0` or a non-zero digit followed by digits. **Error body** (M0): `{"error": code, "message": text, …extra}`.

2. **One request path.** `_wire.py` builds a `Request(method, path, query, headers, json_body, idempotent)` and parses responses; `_transport.py` sends it with `httpx.Client`/`httpx.AsyncClient` (created with `base_url`, `timeout`, `transport`, headers `{"User-Agent": "operon-client-python/0.0.1"} | headers`). 3. **Errors.** A non-2xx response whose body parses as a JSON object with a string `error` is mapped by `error` code (table in the wire contract); an unknown code is mapped by status (400 → `InvalidArgumentError`, 404 → `NotFoundError`, 409 → `ConflictError`, 416 → `OffsetOutOfRangeError` when the three extras are present, else `OperonError`, 503 → `UnavailableError`, 504 → `OperonTimeoutError`, other 5xx → `InternalError`, else `OperonError`), keeping `code` as sent. 4. **Retries (Ruling 5).** Attempt `n` (1-based) of a retry sleeps `min(backoff_max, backoff_base * 2 ** (n - 1)) * (0.5 + 0.5 * random())`; when the response has `Retry-After` as an integer number of seconds `s`, it sleeps `max(that, s)`, and `s > 30` stops retrying. Retried: status 503 on any request with `idempotent = True`; `httpx.ConnectError` and `httpx.ConnectTimeout` on any request; `httpx.ReadTimeout`, `httpx.ReadError`, `httpx.RemoteProtocolError` and `httpx.WriteError` only when `idempotent`. Produce (W4) is `idempotent = False`; every other request is `True`. After the last attempt the mapped error (or `TransportError` from the httpx error) is raised.
5. **Timeouts.** Each attempt uses `timeout`; a fetch with `max_wait_ms = w` uses `timeout + w / 1000` for that request.
6. **Tokens.** `ConsistencyToken.parse` accepts exactly the grammar in the wire contract, with stream and offset ≤ 2^64 − 1 and partition ≤ 2^32 − 1, and rejects duplicate (stream, partition) pairs. **Semantics:**
1. Encoding follows the wire contract's encoder rules exactly. `datetime.datetime` field values are encoded as RFC 3339 (`isoformat()`, a naive datetime raises `ValueError`); `datetime.date` as `YYYY-MM-DD`.
2. `q.text(str, fields=())` → `QueryString(query, default_fields=[])`; one field → `Match(field, query)`; several → `MultiMatch([(f, 1.0) for f in fields], query)`.
3. `SearchBuilder.build()`: when there are two or more retrievers and no `fuse()`, the fusion is `Rrf(60)`; with one or zero, `None` unless set. `limit` must be ≥ 1, `offset` ≥ 0, every `k` ≥ 1, otherwise `ValueError`.
4. Vectors: a `VectorLike` with `.tolist()` is converted with it; every element must be an `int` or `float` (not `bool`) and finite (`math.isfinite`), otherwise `ValueError` naming the vector; ints are sent as floats. A `SparseVector` is checked when constructed (equal lengths, unique non-negative indices below 2^32, finite values; otherwise `ValueError`) and sent in the given order: the server sorts it (overview A27).
5. Consistency (Ruling 6): `"strong"` sends nothing; `"eventual"` adds `"consistency": "eventual"` to W11/W13 bodies and `"consistency": "eventual"` in the SearchRequest; a token (or `str`, parsed) sets header `Operon-Consistency-Token` and, in W12, `"consistency": {"at_least": "<token>"}`; a `Pin` sends `"consistency": {"pinned": {"manifest_version": n, "token": "<token>"}}` in the W11, W12 and W13 bodies and no header (a pinned body wins on the server, M1.2 Task 11 rule 1). W12 bodies always carry `consistency` (`"strong"` by default).
6. `Collection.upsert/patch/delete` are `write` with one op per item; `write` sends one W10 request (atomic across partitions, §6.2), `idempotent = True`. An empty `ops` sequence raises `ValueError` without a request.

2. **JSON (`json.ts`).** `encode(value)` is `JSON.stringify` with a replacer that throws `RangeError` on a non-finite number (naming the key path) and turns a `bigint` into `JSON.rawJSON(value.toString())`. `decode(text)` is `JSON.parse` with a reviver that turns a number whose `context.source` is an integer literal (`/^-?\d+$/`) outside `Number.isSafeInteger` into `BigInt(context.source)`; when the runtime passes no `context`, numbers stay numbers. 3. **Ids (`wire.ts`).** `encodeId`: a `number` must be a safe non-negative integer (else `RangeError`: "use a bigint for ids above 2^53 − 1"); a `bigint` must be in `0n..2n**64n - 1n`; a string is sent as is; `{uuid}` must match `/^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/` (lowercased first); anything else `TypeError`. **Semantics:**
1. **`search`** (title "Search a collection"; description: "Hybrid search over an Operon collection: BM25 full-text search on `query`, nearest-neighbour search on `vector`, or both fused with reciprocal rank fusion. Operon computes no embeddings: pass `vector` only if it comes from the same model as the collection's vectors. `filter` is an object of field conditions that must all hold: a value (equals), a list (any of), {\"gte\": …, \"lt\": …} (range), {\"exists\": true|false}, or null (missing)."):
   1. `query` (after trimming) or `vector` must be present, else `invalid_argument`. `limit` defaults to 10 and must be in `1..=search_max_limit`.
   2. `get_collection(ns, collection)` (errors map as Task 7).
   3. Text retriever when `query` is present: fields = `fields` or every `FieldSpec` of kind `Text` in schema order; none → `invalid_argument` ("collection `c` has no text fields"); a named field that is not a text field → `invalid_argument`.    4.    5. `k` = `limit` with one retriever; with two, each gets `k = min(max(4 * limit, 50), 1000)` and `fusion = Some(Fusion::Rrf { k: 60 })`.
   6. `filter` = `translate_filter(input.filter)`; `consistency` = `AtLeast(token)` when `consistency_token` parses, else `Strong`; `sort: vec![]`, `offset: 0`, `search_after: None`, `score_threshold: None`, `select` = source `SourceFilter::Paths { include: select, exclude: [] }` or all, no vectors, no fields; `aggregations`, `highlight`, `group_by` `None`; `track_total_hits: TrackTotalHits::None`.

2. **`translate_filter`**: entries in key order (`serde_json::Map` is ordered by key). Per entry `(field, v)`: a string/number/bool → `Term { field, value: field_value(v) }`; a non-empty array of scalars → `Terms` (an empty array or a non-scalar element → `invalid_argument`); an object whose keys are a non-empty subset of `{gt, gte, lt, lte}` with scalar values → `Range`; `{"exists": true}` → `Exists`, `{"exists": false}` → `Bool { must_not: [Exists], .. }`; `null` → `IsNull`; anything else → `invalid_argument` ("filter on `field`: expected a value, a list of values, {gt, gte, lt, lte} or {exists}"). 4. **`memory_write`** (title "Write a memory"; description: "Store a memory (text with optional tags, author, metadata and an embedding vector) as a document in a memory collection (default `memories`, created on first use). Returns the memory's id; writing again with the same id replaces it. Search sees it immediately."):
   1. Validate: `text` non-empty and ≤ 1 048 576 bytes; ≤ 64 tags, each 1–256 bytes; `id` 1–512 bytes; `author` ≤ 256 bytes; `vector` non-empty and ≤ 65 535 elements. Violations → `invalid_argument`.
   2. `ns` as Task 7; `c = collection.unwrap_or(config.memory_collection)`; `collections.ensure_namespace(ns)`.
   3. `get_collection(ns, c)`: on `NotFound` (kind `"collection"`), `create_collection(ns, c, memory_schema(vector.map(len)), None)`; `Ok` → `created_collection = true`; `AlreadyExists` (a concurrent creator) → `get_collection` again, `created_collection = false`.
   4. `is_memory_collection(schema)` must hold, else `not_a_memory_collection` ("collection `c` has no text field `text`").
   5. With a `vector`: if the schema has `embedding`, its `dim` must equal the length (else `schema_violation`, field `embedding`); if not, `add_fields(ns, c, vec![], vec![memory_vector(len)])`, and on a `SchemaViolation`/`InvalidArgument` from a concurrent add, `get_collection` once more and re-check the dimension.
   6. `id = input.id` or a new `Ulid` string; document `Document { pk: PrimaryKey::Str(id), source, vectors, sparse_vectors: BTreeMap::new() }` with `source = {"text", "tags": tags or [], "author" (only when given), "metadata": metadata or {}, "created_at": humantime::format_rfc3339_millis(SystemTime::now())}` and `vectors = {"embedding": v}` when given; `write(ns, c, vec![DocOp::Upsert(doc)], WriteOptions::default())`; `consistency_token` = the result's token text.
5. **`memory_schema(dim)`** (exact): `CollectionSchema { version: 1, fields: [FieldSpec { name: "text", source_path: "text", kind: Text { analyzer: "standard", positions: true }, indexed: true, fast: false, ignore_malformed: false }, FieldSpec { name: "tags", source_path: "tags", kind: Keyword, indexed: true, fast: true, ignore_malformed: false }, FieldSpec { name: "author", source_path: "author", kind: Keyword, indexed: true, fast: true, ignore_malformed: false }, FieldSpec { name: "created_at", source_path: "created_at", kind: Date, indexed: true, fast: true, ignore_malformed: false }, FieldSpec { name: "metadata", source_path: "metadata", kind: Json, indexed: true, fast: false, ignore_malformed: false }], vectors: dim.map(memory_vector) as a 0- or 1-element list, sparse_vectors: vec![], dynamic: DynamicMapping::Ignore, max_fields: 1000, annotations: BTreeMap::new() }`; `memory_vector(dim) = VectorSpec { name: "embedding", dim, distance: Distance::Cosine, element: VectorElement::F32, index: VectorIndexSpec::Auto, hnsw: HnswParams::default(), quantization: None }`.
6. **`ensure_namespace`** (only if Task 0 found it missing, in `operon-query`): creates the namespace through the service's `Arc<dyn MetaStore>` (M1.2a) when absent; `NamespaceExists` counts as success; retry-safe.
